# Elementor-шаблон DaKaRaTech

## Файлы

- `dakaratech-elementor-template.json` — шаблон страницы для импорта в Elementor.
- `images/` — PNG-картинки (прозрачный фон), использованные в шаблоне:
  - `logo-horizontal.png` — логотип (значок + надпись), используется в шапке и футере
  - `logo-mark.png` — только знак (волны), без надписи — на случай отдельного использования
  - `favicon.png` — знак на белом круглом фоне, для иконки сайта
  - `hero-illustration.png` — иллюстрация фильтра в hero-блоке
  - `icon-droplet.png` — иконка капли (для карточек RO- и Soft-моделей)
  - `icon-cartridge.png` — иконка картриджа (для карточек Magistral-моделей)

## Как подключить картинки

В JSON-шаблоне ссылки на картинки временно указывают на заглушку:
`https://YOUR-SITE.kz/wp-content/uploads/dakaratech/<имя>.png`

Перед импортом:
1. Загрузите все файлы из `images/` в Медиатеку WordPress (Медиафайлы → Добавить новый).
2. Замените `https://YOUR-SITE.kz/wp-content/uploads/dakaratech` в JSON-файле на реальный путь к папке загрузок вашего сайта (обычно вида `https://ваш-домен.kz/wp-content/uploads/2026/03`) — можно сделать через «Найти и заменить» в любом текстовом редакторе перед импортом.
3. Либо импортируйте шаблон как есть, а затем в каждом Image-виджете нажмите «Choose Image» и выберите загруженный файл из медиатеки вручную — Elementor подставит правильный URL и attachment ID сам.

## Импорт шаблона

WordPress → Шаблоны Elementor → «Все шаблоны» → «Импортировать шаблоны» → выбрать `dakaratech-elementor-template.json`.

## На что обратить внимание

- Форма заявки и сравнительная таблица собраны как HTML-виджет (сырой HTML) — работают в бесплатной версии Elementor, но форма не отправляет данные без бэкенда (для реальной отправки нужен Elementor Pro Form, WPForms или Contact Form 7 + шорткод).
- Шрифты Unbounded (заголовки) и Manrope (текст) нужно подключить отдельно — через плагин Google Fonts для Elementor или Custom Fonts в Elementor Pro, иначе применится шрифт темы по умолчанию.
- Иконки — стандартные FontAwesome-иконки (`fa-tint`, `fa-wrench` и т.д.), должны подхватиться автоматически.
