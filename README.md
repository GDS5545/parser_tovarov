# parser_tovarov

Скрипт для сбора товаров с каталога сайта (например,
`https://habarovsk.vagner-ural.ru/katalog/`) и экспорта их в CSV,
совместимый с импортёром WooCommerce Product CSV (тот же набор колонок,
что и в `samples/wc-product-export-template.csv`).

## Важное ограничение окружения

В этой среде выполнения исходящий доступ к произвольным сайтам (в т.ч.
к `vagner-ural.ru`) заблокирован сетевой политикой — автоматически
скачать страницу каталога отсюда нельзя. Поэтому текущий пайплайн
работает с уже сохранённым HTML страницы:

1. Сохраните HTML страницы каталога (в браузере: "Сохранить как" или
   просмотр исходного кода) в файл, например `samples/habarovsk-katalog.html`.
2. Запустите скрипт, указав тот же базовый URL сайта — он нужен, чтобы
   превратить относительные ссылки на товары и изображения в абсолютные.

```bash
pip install beautifulsoup4
python3 src/scrape_catalog.py samples/habarovsk-katalog.html \
    --base-url https://habarovsk.vagner-ural.ru \
    --out output/habarovsk-katalog.csv
```

Если сетевой доступ к сайту будет разрешён (allowlist egress-прокси),
скрипт можно расширить, чтобы он сам скачивал страницу (и постранично
проходил категории/пагинацию), не меняя логику разбора карточек товара.

## Какие поля заполняются

Со страницы каталога (список карточек `.p-card`) извлекаются:

- **Имя** — название товара
- **Акционная цена / Базовая цена** — текущая (со скидкой) и старая цена
- **Изображения** — абсолютный URL картинки товара
- **Наличие** — по статусу "В наличии" на карточке
- **Краткое описание** — список характеристик карточки (ступени очистки,
  наличие насоса, гарантия, количество картриджей и т.п.) в виде `<ul>`
- **Мета: _uwp_source_url** — исходная ссылка на страницу товара (для
  отслеживания источника и повторной синхронизации)
- **Мета: _uwp_content_hash** — md5-хэш от имени/цен/характеристик, чтобы
  при повторном запуске можно было понять, изменился ли товар

Поля, которых нет в карточке списка каталога (Артикул, полное
Описание, Категории, Бренды, атрибуты) намеренно оставлены пустыми —
эти данные есть только на странице конкретного товара, а не в списке
каталога. Чтобы их заполнить, нужно спарсить страницы отдельных товаров
(`/product/<slug>/`) аналогичным образом и объединить с этим CSV по
`Мета: _uwp_source_url`.

## Файлы

- `src/scrape_catalog.py` — парсер + экспорт в CSV
- `samples/habarovsk-katalog.html` — сохранённая страница каталога
  (57 товаров, `/katalog/` → `/list/`)
- `samples/wc-product-export-template.csv` — образец формата импорта
  WooCommerce, под который подгоняются колонки
- `output/habarovsk-katalog.csv` — готовый результат разбора
