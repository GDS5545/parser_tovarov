# parser_tovarov

Universal Woo Product Parser — плагин WordPress, который обходит каталог
указанного сайта-источника, распознает карточки товаров на любом движке и
импортирует их в WooCommerce с правильным деревом категорий.

## Установка

1. Собрать zip: `zip -r universal-woo-product-parser.zip universal-woo-product-parser`
2. WordPress → Плагины → Добавить новый → Загрузить плагин → выбрать zip.
3. Активировать. Пункт меню появится в WooCommerce → «Парсер товаров».

## Быстрый старт

Указать домен источника, нажать «Запустить». Остальное плагин делает сам:
находит карту сайта, обходит разделы, отличает карточки от обычных страниц,
создает категории по хлебным крошкам и товары в каталоге.

Подробности — в [`universal-woo-product-parser/readme.txt`](universal-woo-product-parser/readme.txt).

## Структура

```
universal-woo-product-parser/
├── universal-woo-product-parser.php   загрузчик плагина
├── uninstall.php                      полная очистка при удалении
├── assets/                            стили и скрипт админки
└── includes/
    ├── class-uwp-settings.php         настройки и их санитайз
    ├── class-uwp-db.php               единая очередь задач и журнал
    ├── class-uwp-http.php             загрузка страниц, кодировки, лимиты
    ├── class-uwp-url.php              нормализация URL и границы обхода
    ├── class-uwp-dom.php              DOM + CSS-селекторы
    ├── class-uwp-extractor.php        универсальное распознавание страницы
    ├── class-uwp-crawler.php          обход сайта и очередь
    ├── class-uwp-importer.php         товары и категории WooCommerce
    ├── class-uwp-runner.php           фоновые тики, защита от зависаний
    ├── class-uwp-admin.php            экран администратора
    └── class-uwp-plugin.php           сборка хуков
```

## Принципы

- **Универсальность вместо профилей.** Тип страницы и данные товара берутся из
  JSON-LD, микроразметки, OpenGraph и структурных признаков — в таком порядке.
  Ручные CSS-селекторы нужны только как исключение.
- **Один домен.** Обходится строго домен из настроек; источник проверяется
  повторно перед созданием товара.
- **Короткие тики.** Работа идет фоном порциями с бюджетом по времени,
  памяти и числу запросов — веб-сервер никогда не ждет парсер.
- **Идемпотентность.** Повторный запуск обновляет ранее импортированные
  товары и переиспользует существующие категории, не создавая дублей.
