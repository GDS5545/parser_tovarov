# AquaLine — сайт по продаже систем очистки воды

Статический сайт-визитка для продажи фильтров и систем очистки воды для дома (обратный осмос, магистральные фильтры, умягчение воды). Вёрстка вдохновлена структурой и стилистикой лендингов автомобильных брендов (тёмная тема, крупный hero-блок, каталог, преимущества, отзывы, форма заявки).

## Структура

```
index.html            — главная страница (все секции)
assets/css/style.css  — стили
assets/js/main.js     — интерактив (меню, табы каталога, FAQ, модалка, формы)
```

## Разделы страницы

- Шапка с навигацией и телефоном
- Hero с заголовком, статистикой и CTA
- Полоса доверия (сертификаты, гарантия, рассрочка)
- Преимущества компании
- Каталог систем с фильтрацией по типу (осмос / магистральные / умягчение)
- Как проходит покупка и установка (4 шага)
- Таблица сравнения систем
- О компании и статистика
- Отзывы клиентов
- FAQ (аккордеон)
- CTA-баннер
- Контакты и форма заявки + плавающая кнопка обратного звонка
- Футер

## Запуск

Открыть `index.html` в браузере — сборка не требуется. Формы на странице работают только на фронтенде (показывают уведомление об отправке); для реальной отправки заявок нужно подключить бэкенд/API.
