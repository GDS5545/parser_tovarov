# Parser Tovarov

WordPress/WooCommerce-плагин: табличный каталог товаров с фильтрами, быстрыми
кнопками, корзиной и отправкой заявки в Bitrix24.

Плагин лежит в [`parser-tovarov/`](parser-tovarov) — скопируйте эту папку в
`wp-content/plugins/` и активируйте в админке (требуется активный WooCommerce).

## Возможности

1. **Таблица товаров** — собирается из товаров WooCommerce одной или
   нескольких категорий одним шорткодом.
2. **Фильтр и быстрые кнопки** — выпадающие списки по атрибутам товара
   (марка, диаметр, ГОСТ и т.п.) с поиском внутри списка, плюс строка
   быстрых кнопок-чипов по самому популярному атрибуту.
3. **Корзина и заказ** — «Купить» добавляет товар в корзину WooCommerce и
   сразу открывает панель корзины с двумя действиями: **«Оформить заказ»**
   (форма имя/телефон/комментарий/файл → заявка сохраняется в админке и
   уходит в Bitrix24 через входящий вебхук) или **«Продолжить выбор на
   сайте»** (просто закрыть корзину и продолжить выбирать товары).
4. **Производительность** — таблица показывает товары нескольких категорий
   постранично через AJAX (не загружает весь каталог сразу), списки
   значений фильтров кэшируются, а JS/CSS подключаются только на страницах,
   где реально используется шорткод.

## Быстрый старт

```
[ptv_catalog
	categories="truby-nerzhaveyuschie,krug-nerzhaveyuschij"
	attributes="marka,diametr,tolschina-stenki,gost"
	quick_filter="marka"
	title="Труба нержавеющая"
]
```

Настройки плагина (вебхук Bitrix24, минимальная сумма заказа, товаров на
странице и т.д.) — в админке: **Каталог товаров → Настройки**. Полное
описание всех параметров шорткода — на вкладке **Как пользоваться**.
