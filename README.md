# Elementor Order Popup

WordPress-плагин, который превращает кнопки в виджетах Elementor («Заказать», «Купить» и любые другие) в кнопки добавления товара в popup-форму заявки. Посетитель может добавить в заявку несколько разных товаров, а сама форма отправляет заказ одновременно в **Bitrix24** (CRM) и в **Telegram**.

Работает с любыми виджетами Elementor (Button, Price Table, Icon Box и т.д.) и не требует Elementor Pro.

## Возможности

- Перехватывает клики по кнопкам с текстом «Заказать», «Купить» и т.п. (список настраивается) или по кнопкам с CSS-классом `eop-order-btn`.
- Автоматически определяет название, цену и картинку товара из ближайшего окружения кнопки (заголовок, блок цены, изображение), либо берёт их из data-атрибутов, если они заданы вручную.
- Открывает popup с корзиной заявки: можно добавить несколько товаров (клики по разным кнопкам на странице накапливаются), менять количество, удалять позиции.
- Форма: имя, телефон, email (можно сделать обязательным), комментарий. Есть скрытая honeypot-защита от спам-ботов.
- При отправке заявка уходит в Bitrix24 (создаётся Лид или Сделка через входящий вебхук) и/или в Telegram (через Bot API), в зависимости от того, что включено в настройках.
- Все тексты, ключевые слова-триггеры и валюта настраиваются в админке: **Настройки -> Order Popup**.

## Установка

1. Скопируйте папку плагина в `wp-content/plugins/elementor-order-popup`.
2. Активируйте плагин в **Плагины -> Установленные плагины**.
3. Перейдите в **Настройки -> Order Popup** и заполните нужные разделы.

## Настройка кнопок Elementor

По умолчанию плагин ловит клики по кнопкам, чей текст совпадает с одним из ключевых слов (заказать, купить, order, buy now и т.д. — список редактируется в настройках).

Чтобы кнопка точно распознавалась независимо от текста, добавьте ей CSS-класс:

1. Откройте кнопку в редакторе Elementor.
2. Вкладка **Advanced -> CSS Classes** (Дополнительно -> CSS-классы).
3. Впишите `eop-order-btn`.

### Как задаётся название/цена товара

Плагин ищет название и цену рядом с кнопкой (заголовок в той же колонке/секции, блок цены, изображение). Если авто-определение работает не точно, можно явно указать данные через data-атрибуты — например, добавив HTML-виджет рядом или через "Custom Attributes" в Elementor Pro на самой кнопке:

```
data-eop-title="Название товара"
data-eop-price="15000"
data-eop-sku="sku-123"
data-eop-image="https://example.com/image.jpg"
data-eop-url="https://example.com/product/123"
```

Если ни один атрибут не задан, плагин возьмёт заголовок/цену/картинку из ближайшего блока Elementor вокруг кнопки.

## Настройка Bitrix24

1. В Bitrix24: **Разработчикам -> Другое -> Входящий вебхук**, права доступа — раздел «CRM».
2. Скопируйте URL вебхука (вида `https://your-domain.bitrix24.ru/rest/1/xxxxxxxxxxxxxxxx/`) в настройки плагина.
3. Выберите, что создавать — Лид или Сделку.

## Настройка Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите токен.
2. Добавьте бота в нужный чат/канал и узнайте его `chat_id` (например, через @userinfobot или получив апдейты бота через `getUpdates`).
3. Впишите токен и chat_id в настройки плагина.

## Структура плагина

```
elementor-order-popup.php        Точка входа плагина
includes/class-eop-settings.php  Страница настроек
includes/class-eop-assets.php    Подключение JS/CSS, передача настроек в JS
includes/class-eop-ajax.php      Обработка отправки формы (AJAX)
includes/class-eop-integrations.php  Отправка в Bitrix24 и Telegram
assets/js/eop-frontend.js        Перехват кнопок, корзина, popup, отправка
assets/css/eop-frontend.css      Стили popup
```

## Хуки для разработчиков

- `eop_before_send_order( $order )` — перед отправкой в Bitrix24/Telegram (можно, например, сохранить заявку в свою таблицу).
- `eop_after_send_order( $order, $results )` — после отправки, `$results` содержит результат по каждому каналу.
