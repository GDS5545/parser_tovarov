# Elementor: сетка товаров (в стиле aquasoft.kz/list/)

`product-grid.json` — шаблон секции Elementor (на flex-контейнерах) с сеткой
карточек товаров: фото, бейдж («-20%», «Хит», «Новинка»), название, старая/новая
цена и кнопка «В корзину». При наведении карточка приподнимается и получает
более глубокую тень.

Прямой доступ к aquasoft.kz из этой среды заблокирован сетевым прокси, поэтому
шаблон — это добросовестная реконструкция типичной раскладки товарной сетки
(карточка со скруглёнными углами, мягкая тень, ценник с акцентным цветом), а не
точная копия пиксель-в-пиксель. Цвета и текст — плейсхолдеры, под замену.

## Импорт в Elementor

1. Elementor → Templates → Saved Templates → Import Template.
2. Выбрать `product-grid.json`.
3. Открыть шаблон в редакторе и вставить на нужную страницу (Insert Template).

Требуется Elementor с включёнными Flexbox-контейнерами (в актуальных версиях
это поведение по умолчанию).

## Что поменять под свой стиль

- Цвет `#1E7A5F` (акцент/кнопка) и `#E63946` (бейдж скидки) — в начале
  генератора `../scripts` или прямо в JSON через Ctrl+F по `1E7A5F` / `E63946`.
- Изображения — сейчас placeholder-ссылки `placehold.co`, заменить на медиа
  из вашей библиотеки/парсера товаров.
- Количество карточек в ряду регулируется через `flex_gap` и ширину карточки
  (`_flex_basis`/`width`) в настройках дочернего контейнера-карточки; для
  адаптива задайте отдельные значения ширины на вкладках Tablet/Mobile в
  редакторе Elementor (сами по себе responsive-ключи не переносятся надёжно
  между версиями Elementor через голый JSON, поэтому в шаблоне заданы только
  базовые/desktop значения).
- Текст кнопки, цены и названия — обычные текстовые поля в самом Elementor.

## Если нужна точная копия сетки с aquasoft.kz

Пришлите скриншот страницы `/list/` или опишите словами: количество колонок,
цвета, наличие рамки/тени у карточки, где расположены кнопка и цена — и я
подгоню шаблон один в один.
